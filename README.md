# hxwl-06 显微镜玻片观察 · 可追溯流程

把静态观察表升级为「样本 → 观察记录 → 复核任务 → 操作留痕」的完整可追溯流程。

## 技术栈

React 19 + Vite + TypeScript + 本地 IndexedStorage（localStorage，含两阶段写入与检查点）

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5106
npm run selftest   # 领域规则自检（78 条断言）
npm run build      # tsc 类型检查 + 生产构建
```

## 统一处理状态（明细 / 待办 / 统计同一口径）

| 状态 | 含义 |
| --- | --- |
| 待核 PENDING_VERIFY | 旧数据缺染色批次版本，管理员补核前不进入复核队列 |
| 待复核 PENDING_REVIEW | 学生提交（或补核 / 标尺重算）后等待教师复核 |
| 冲突保留 CONFLICT | 同一玻片并发提交的后到内容，保留但不生效 |
| 已复核 APPROVED | 教师通过，结论按复核当时的批次版本与标尺冻结 |
| 已驳回 REJECTED | 教师驳回，学生可修改后重提 |
| 已失效 INVALIDATED | 批次过期/停用、复议发回等，原结论无效需重做 |
| 已复核·待复议 RECONSIDER | 依据已更新，原结论保留，复议项等待教师裁决 |

## 规则与实现位置

- **越权代写拒绝**：教师/管理员代交、学生 A 替学生 B 交均被拒绝，拒绝本身写入审计留痕
  （`src/domain/reducer.ts` 的 `submitObservation` 分支）。
- **按批次×倍数复核**：复核队列按 `染色批次版本 × 放大倍数` 分组，支持整组通过；
  批次不在有效期或版本对不上时禁止复核；通过即冻结依据快照（`basisSnapshot`）。
- **管理员调整依据后的级联**（`cascadeBatchChange`）：
  - 未复核结论：批次过期/停用 → **立即失效**；标尺版本变更 → **按新系数重算并跟随新版本**，继续待复核；
  - 已复核结论：状态与测量值不动，**保留复核当时依据快照并生成复议项**；教师可「维持」或「发回重做」。
- **并发提交**：同一玻片 2 分钟窗口内，先到结论生效，后到内容以「冲突保留」留档并指向先到记录；
  管理员页可发起两人同刻提交演练（同刻时按学号确定性决胜）。
- **检查点恢复**：每次成功命令两阶段写入（pending→读回校验→覆盖主状态）并生成带 FNV-1a 校验和的检查点；
  写入/导入失败整体回滚到最近完整检查点；主数据损坏时重载自动恢复；可手动恢复到任意检查点。
- **重复提交去重**：幂等键 = 观察者+玻片+倍数+原始读数，重复提交不生成第二条记录（导入同样去重）。
- **旧数据待核**：迁移/导入中缺批次版本的记录一律先「待核」，统计、待办、明细都展示同一状态；
  管理员补核绑定批次后按当前标尺重算进入复核队列。
- **导入事务**：整批校验，任一行非法（样本不存在等）整体不落库。
